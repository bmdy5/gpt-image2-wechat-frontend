# Visionary AI — 微信小程序前端客户端

本项目是为 Visionary AI 图像生成服务定制的微信小程序客户端。采用微信原生开发框架（JavaScript/WXSS/WXML）构建，针对移动端环境进行了深度交互优化，并集成了静默会话自愈、同层渲染防崩、异步长轮询状态机以及微调迭代等企业级客户端技术。

---

## 核心技术特性

### 1. 微信静默授权与会话自愈机制
* **无感 Token 续签**：通过在网络请求工具模块中植入 HTTP 401 响应拦截器，当检测到 JWT 凭证失效时，系统自动挂起当前的网络请求线程。
* **Promise 请求重放队列**：利用 `silentLogin()` 接口调用微信官方 `wx.login` 获取临时登录凭证 `code`，并在后端完成会话凭证兑换。刷新期间，所有并发的业务请求将被有序推入重放队列（`refreshQueue`），待新 JWT 写入持久化存储后进行逐一重放，保障用户交互不中断。

### 2. 非阻塞异步生图与长轮询状态机
* **生成进度实时解耦**：针对 AI 图像生成通常需要 10 至 30 秒的物理延迟问题，客户端摒弃了长连接挂起方式，采用“即时响应 + 状态轮询”的异步通信模式。
* **增量进度指示**：发起生成请求后，客户端立刻接收 Pending 状态，并激活 `generationPollTimer` 定时器。以固定时间步长（如 2 秒）向后端拉取实时渲染进度（0% - 100%），并在画廊卡片上以平滑渐变进度条反馈给用户。

### 3. Canvas 2D 物理避让与同层渲染防崩溃策略
* **Stardust Canvas 粒子引擎**：首页集成了基于 Canvas 2D 的高性能交互式粒子系统，用于提供视觉动效。
* **物理生命周期销毁机制**：微信小程序的同层渲染机制（Same-Layer Rendering）在页面切换和分包加载时，若未及时清理 WebGL/Canvas 上下文句柄，易诱发底层 GPU 资源挂起甚至客户端 Crash。本项目在 `onUnload` 以及 `switchTab` 离开首页的生命周期钩子中，强制停止粒子更新循环，注销动画帧句柄（`cancelAnimationFrame`），在切换回首页时进行重构与上下文重新绑定，确保内存占用平稳。

### 4. 20 种风格预设模板与多维级联降级控制
* **风格元数据管理**：内置极致写实、商业大片、老照片修复、国风月夜等 20 种预设视觉风格模板。
* **级联权限降级**：客户端根据用户选择的“普通（5点）”、“进阶（10点）”、“旗舰（15点）”三档计费模式，通过正则表达式及权限过滤器级联控制可选的风格预设。低级别账号若强行关联高级风格，系统将触发降级安全校验并引导自动重置，避免接口参数越权报错。

### 5. 魔法棒微调迭代窗口
* **时空限时迭代**：对于进阶及旗舰模式生成的画作，客户端支持在生成完成起的 10 分钟时空窗口内，使用“魔法棒”功能载入父级特征图谱和原始提示词进行免费的增量微调。
* **倒计时状态同步**：客户端本地启动高精度定时器，将截止时间（10分钟窗口）转换为可视化时间字符串实时渲染，过期后自动触发模式退回，确保账单系统的幂等性与对账一致性。

## 技术架构

| 模块维度 | 技术选型与实现标准 |
| :--- | :--- |
| **基础开发框架** | 微信原生 Mini Program 框架 (MINA 架构) |
| **脚本控制逻辑** | JavaScript (ES6+ 标准) |
| **视觉呈现样式** | WXSS (Css 局部隔离架构, 包含安全区避让、毛玻璃滤镜与高阶过渡动画) |
| **网络通信层** | 封装 `wx.request`，实现带 JWT 拦截与 Promise 链式调用的异步 HTTP 客户端 |
| **图形渲染引擎** | 原生 Canvas 2D 物理粒子避让模型 |

## 运行与配置指南

### 1. 环境依赖
* 安装 **微信开发者工具** 稳定版。
* 本地或云端需部署有状态的 **微信小程序专属后端服务**（默认端口 `8002`）。

### 2. 本地开发配置
* 导入本项目文件夹到微信开发者工具。
* 客户端会自动检测小程序当前的运行环境（`develop` 或 `production`）。
* 在本地测试时，网络接口的 `BASE_URL` 会自动路由至 `http://localhost:8002/api`。
* 确保在微信开发者工具的项目设置中勾选 **“不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书”**，以允许本地 HTTP 环回测试。

### 3. 生产环境配置
* 在 `utils/api.js` 中配置生产环境的 API 域名：
  ```javascript
  let BASE_URL = 'https://gpt-image2.xiaoliang.tech/api';
  ```
* 在微信小程序管理后台的“开发管理 - 开发设置 - 服务器域名”中，将您的生产域名 `https://gpt-image2.xiaoliang.tech` 配置到 `request` 合法域名列表中。
